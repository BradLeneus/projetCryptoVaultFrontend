Notes pour utiliser Github:

1.git init (initialiser)
2.git status
3. git add -A (ajouter tous les fichiers
4.git commit -m  "message de commit"
5.git checkout -b dev (créer une branche)
6.git remote add origin https://github.com/BradLeneus/atelier1ProjetWeb.git (ajouter le repo GitHub au projet)
7. git push -u origin dev(envoyer au repo GitHub)
8.git log (Voir l'historique des commits)




-Git merge : regrouper toutes les changements faits aux branches de chaque développeurs
-Avant de faire un git merge, faire un git pull

-Faire un git push après le git merge


-TOUJOURS FAIRE git remote add origin url avant de cloner le repo

-si on on ne voit pas tous les branches, faire  git fetch --all pour tous les récupérer.
